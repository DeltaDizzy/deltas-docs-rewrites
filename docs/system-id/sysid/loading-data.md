# Loading Data

After retriving your DataLog file with your test data, it must be loaded into SysId. Upon opening the application, you will be greeted by the following view:

![The SysId window when first opened, showing blank graphs, analysis, and Data Loader panes](/docs/system-id/media/sysid/sysid_window.png)

At first, we will focus on the Log Loader and Data Selector panels at the far left of the window.

Using the `Open data log file...` button, select and load your test DataLog.
